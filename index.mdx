smoltcp is a Rust TCP/IP networking library built for embedded and real-time systems. It runs without an OS, without heap allocation, and achieves ~Gbps throughput. Whether you are writing firmware for a microcontroller or testing network protocols in userspace, smoltcp gives you full control over every layer of the stack.

## What smoltcp provides

<CardGroup cols={3}>
  <Card title="TCP & UDP sockets" icon="network-wired" href="/concepts/sockets">
    Full TCP state machine with congestion control, retransmission, and keep-alive. UDP with checksum validation.
  </Card>
  <Card title="IPv4 & IPv6" icon="globe" href="/protocols/ipv4">
    Dual-stack support including fragmentation, reassembly, multicast, and SLAAC.
  </Card>
  <Card title="6LoWPAN" icon="wifi" href="/protocols/sixlowpan">
    Compressed IPv6 over IEEE 802.15.4 for low-power IoT devices.
  </Card>
  <Card title="DHCPv4 & DNS" icon="server" href="/examples/dhcp">
    Built-in DHCP client and DNS resolver sockets for hosted environments.
  </Card>
  <Card title="No heap required" icon="microchip" href="/guides/bare-metal">
    All buffers are caller-supplied slices. Works on any `no_std` target.
  </Card>
  <Card title="Async support" icon="bolt" href="/concepts/interface">
    Poll-based event loop with optional async/await via the `async` feature.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Add smoltcp to Cargo.toml">
    Choose the features you need and add the dependency:

    ```toml Cargo.toml
    [dependencies]
    smoltcp = { version = "0.13.0", default-features = false, features = [
        "proto-ipv4", "socket-tcp", "medium-ethernet", "log"
    ]}
    ```
  </Step>
  <Step title="Implement the Device trait">
    Wrap your hardware driver in the `phy::Device` trait to connect smoltcp to your network interface.
  </Step>
  <Step title="Create an Interface and SocketSet">
    Configure an `Interface` with your IP address and routes, then create a `SocketSet` to hold your sockets.
  </Step>
  <Step title="Poll the interface in your main loop">
    Call `iface.poll()` in your event loop to drive all protocol state machines and socket I/O.
  </Step>
</Steps>

<Note>
  smoltcp compiles on stable Rust 1.91 and later. Use `default-features = false` for bare-metal targets to avoid pulling in `std`.
</Note>
